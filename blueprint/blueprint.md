# Vibe Project Harness Blueprint

## Goal
Create a local AI engineering control core that manages project memory, context, health and handoff for long-lived Vibecoding projects.

## Actors

- Human
- Planning AI
- Harness Agent (Claude Code CLI + DeepSeek)
- Development Agent (Codex CLI)

## Principles

- Local first
- No account system
- Project embedded
- Git version controlled knowledge
- Human approval for optimization
